# 3D 看房 · house-tour

[![Deploy to GitHub Pages](https://github.com/hzh20070706-gif/house-tour/actions/workflows/deploy.yml/badge.svg)](https://github.com/hzh20070706-gif/house-tour/actions/workflows/deploy.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![three.js r180](https://img.shields.io/badge/three.js-r180-black)

浏览器里的第一人称看房应用。导入户型模型或自己描户型图，就能像玩游戏一样在房子里走动，一条链接发给客户即可。

**在线试玩：** <https://hzh20070706-gif.github.io/house-tour/> （纯静态版，可以导入模型、用户型图建房、看样板间；「上传到服务器」只在本地 `npm start` 时可用）

- 纯前端，没有构建步骤，`npm start` 就能跑
- 依赖全部离线内置（three.js 放在 `vendor/`），不依赖外网 CDN
- 手机上打开同一个局域网地址就能用，左半屏摇杆 + 右半屏拖动转头

---

## 快速开始

```bash
cd D:\house-tour
npm install      # 已装过就跳过
npm start
```

终端会打印两个地址：

```
本机打开    http://localhost:5173/
手机打开    http://192.168.x.x:5173/   ← 同一 WiFi
```

把手机地址发给客户，他在浏览器里就能走。

## 三种进入方式

| 方式 | 适合场景 | 需要准备什么 |
|---|---|---|
| **导入 3D 模型** | 已有建模文件 | 从 Blender、酷家乐、三维家、酷雷曼等导出的 `.glb` / `.obj` / `.fbx` 等 |
| **用户型图建房** | 手上只有一张平面图 | 一张户型图图片，或者直接手动描 |
| **先看看示例** | 想先确认效果 | 无 |

### 支持的模型格式

`.glb` `.gltf` `.obj` `.fbx` `.stl` `.ply` `.dae` `.3mf`，以及把这些打包在一起的 `.zip`。

`.zip` 是推荐做法：`obj + mtl + 一堆贴图` 这类散装文件直接压成一个包拖进来，程序会在浏览器里解压，贴图自动找到，不用手动一个个选。

另外还支持 Draco 压缩、KTX2 贴图、meshopt 压缩，很多在线导出工具默认就用这些。

### 单位自动识别

模型用毫米、厘米还是英寸导出都没关系。载入后会自动判断尺寸量级，把它拉到 3~45 米的合理范围，界面上会提示「已自动缩放 ×0.001」之类。想手动改的话，在设置里调「视点高度」和行走速度即可。

## 户型图建房怎么用

1. 点「载入平面图」，选一张户型图（拍照、截图、CAD 导出都行）
2. 点「① 在图上点两处已知距离」——在图上点一条你知道真实长度的边（比如标着 3600 的那面墙）的两端，然后在输入框填 `3.6`，点「② 应用」。比例尺就算好了
3. 用「画墙」沿着墙线拖鼠标，一段一段描。端点会自动吸附到已有节点，靠近水平/垂直时会自动拉正
4. 需要门洞就切到「开门洞」，在墙上点一下
5. 点「生成 3D 空间」→ 自动生成墙体、地板、踢脚线，直接进去走

描的时候可以随时 `Ctrl+Z` 撤销，滚轮缩放，按 4 切到平移工具或者按住 `Shift` 拖。

比例标定之后如果再改，已有墙段会跟着等比缩放，不会跑偏。

## 操作方式

### 电脑

| 按键 | 作用 |
|---|---|
| `W` `A` `S` `D` | 前后左右 |
| 鼠标 | 转头，点一下画面锁定视角 |
| `Shift` | 快走 |
| `空格` | 跳 |
| `Q` `E` | 下降 / 上升 |
| `F` | 切换自由飞行（看整体布局） |
| `R` | 回到起点 |
| `M` | 切换小地图大小 |
| `H` | 显示帮助 |
| `Esc` | 松开鼠标 |

### 手机

左半屏按下出现摇杆，右半屏拖动转头。右侧有「跑 / 上升 / 下降」按钮。手机浏览器不支持指针锁定，所以是拖动转头，不是鼠标那种。

## 把房子发给客户

### 方式一：分享链接（推荐）

模型放进 `models/` 文件夹后，客户端会出现在启动页的「服务器上已有的模型」里。打开它，进设置面板点「复制分享链接」，发给客户即可。

链接长这样：`http://你的地址:5173/?m=models/xxx.glb`

户型图建的房子也能分享，墙段数据会编码进链接里（链接会比较长，但能用）。

### 方式二：直接拖文件

客户自己在启动页把模型拖进去。适合临时演示。

### 方式三：上传到服务器

从本机拖入的模型，进设置面板点「上传到服务器」，会存进 `models/` 并自动变成可分享的。

> ⚠️ 目前的服务器是给局域网/内网用的。要真正对外服务，需要：
> - 一个公网可访问的部署（静态托管 + 对象存储放模型）
> - 上传接口加鉴权（现在任何人拿到地址都能上传）
> - 模型加防盗链或签名 URL
>
> 这三件事我没做，因为取决于你打算托管在哪里。需要的话告诉我目标平台。

## 界面说明

- **小地图**：右下角，显示当前楼层的墙体和你的位置。点左上角按钮可以切成「跟随朝向」模式。按 `M` 循环切换大小。按住 `Shift` 点地图放大。
- **截图**：工具条上的 ▣，直接渲染当前画面存成 PNG。
- **视点高度**：设置里可调，`1.6` 米左右最接近真人眼睛。
- **画面精细度**：默认自动——帧率掉下去会自动降档，跑得流畅会自动升档。也可以手动锁死。
- **显示天花板**：默认关闭。关掉时是俯视那种「剖切」效果，方便看整体布局；打开就是正常室内视角。

```
│  ├─ env.js             光照、IBL、天空、阴影
│  ├─ sample.js          内置样板间（含家具）
│  └─ util.js            小工具

├─ assets/               其他素材
├─ scripts/vendor.js     把 node_modules 里的 three.js 拷到 vendor/

```

## 常见问题

**打开是一片黑 / 模型全黑**
检查是不是用 `file://` 打开的。浏览器对本地文件的模块加载和 `fetch` 有限制，必须走 `npm start` 起的服务器。

**模型方向不对（躺着的）**
不同建模软件的上轴不一样。目前没有做自动朝向识别，需要的话在建模软件里摆正再导出。想让我加一个「旋转模型」的开关也可以说。

**模型特别大，加载很久**
1.5GB 以上的模型在浏览器里会很吃力。建议先用 Blender 精简面数、合并贴图、导出成 Draco 压缩的 `.glb`。程序会绕过超大模型的部分装饰做碰撞，保证走得动，但载入时间省不了。

**走不进房间 / 一直卡在墙里**
碰撞体是基于模型自身的三角形生成的。如果模型里的墙是单面片，可能会漏。按下 `F` 切自由飞行看看整体结构，或者调小「视点高度」试试。

**手机上很卡**
画质档位会自动降。也可以手动锁到「流畅」。另外阴影很吃性能，设置里可以关掉。

**点击画面没有锁定鼠标**
浏览器要求必须在用户的点击手势里才能锁定。点一下画面就行。如果点了没反应，检查是不是已经按过 `Esc` 松开了，再点一次即可。

## 已知限制

- 没有做多人同时看房 / 语音讲解
- 没有做房间标注和测量工具
- 没有做浏览路径录制和自动导览
- 全景照片（360 图）模式没做，只支持真 3D 模型
- 上传接口没有鉴权
- 模型朝向不做自动识别

这些都可以加，按优先级来。
